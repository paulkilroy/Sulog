Lesson 9a · II Class Personal Pronouns (cont.)
Guide grammar · II Class Personal Pronouns (cont.)

In lesson 8 you learned how to use the III Class Personal Pronouns below in column I. These pronouns are used to show possession. In this lesson you will learn how to use the pronouns in column II. These pronouns show the BENEFICIARY or the DIRECTION of the action of the verb. These column II pronouns are formed by adding 'Ha' before the corresponding column I pronoun. For example, 'Ha akon' (column II) means 'to (at, with, from) me' or 'to (at, with, from) my...'.
