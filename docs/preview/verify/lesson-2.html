Lesson 2a · I Class Markers
Guide grammar · I Class Markers

Just as there are three classes of personal pronouns in Waray-waray, there are also three classes of markers. A I Class Marker "marks" the TOPIC, or the emphasized word, of the sentence. Markers are used with proper nouns (people's names) and common nouns.

### I Class Markers

SingularPlural
w/ Proper NounsHihira
w/ Common Nounsanan mga
Chart I Class Markers · 3 words
hi—the (before a name)
hira—they
an—the (subject marker)
Guide note

* Ngan is a connector similar to the English conjunction and.

* Remember that mga indicates the noun which follows is plural.

Like the previous lesson, these are equational sentences which do not need a verb. The English translation uses the to be verb.
