# Beginning Waray-Waray — John U. Wolff & Ida O. Wolff (1967)

The only full Waray course written by a linguist together with a native Samareño speaker.
4 volumes, Cornell (self-published, Ithaca NY, 1967). Presents **Tacloban Waray of the late
1960s** (Wolff's own caveat: the language has likely changed substantially since).

**License: CC BY-ND 4.0** — opened on HathiTrust 2026-09 by John U. Wolff himself
(HathiTrust ticket GS-17033; declaration signed 2026-09-07). Attribution required;
**no derivatives without separate permission** — adapting text into lessons needs John's
private OK (asked; see memory `wolff-beginning-waray-hunt`). Language facts (vocabulary,
paradigms) are not copyrightable and are free to use.
